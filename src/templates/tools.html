BibTeX Generation Tools

Generate BibTeX entries from arXiv IDs or DOIs. Paste either:

  • arXiv ID (e.g., 2001.00092)
  • arXiv URL (e.g., https://arxiv.org/abs/2001.00092)
  • DOI (e.g., 10.1002/jgt.22704)
  • DOI URL (e.g., https://doi.org/10.1002/jgt.22704)
JSON API

GET https://arxiv.symmetricfunctions.com/api/bibtex.json?id=2001.00092
or https://arxiv.symmetricfunctions.com/api/bibtex.json?doi=10.1002/jgt.22704
Add &lookup_doi=1 to search Crossref for a publication DOI if not already known.
